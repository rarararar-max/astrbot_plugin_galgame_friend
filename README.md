# 好友 Galgame

把 AstrBot 里的 **QQ 私聊**变成 galgame 场景。

好友给你（机器人）发消息时，插件页面会弹出**立绘 + 对话框 + 三条 AI 生成的回复候选**；
每条候选有不同的策略角度和好感度增减，**点一条就直接发给对方**。
<img width="1433" height="1110" alt="QQ_1790346921984" src="https://github.com/user-attachments/assets/bd8f11e1-9a5b-43ef-9033-9d455290c7c7" />

- 🎭 **立绘随情绪变化** —— AI 根据好友那条消息判断他此刻的情绪，自动切到对应标签的立绘
- 💗 **好感度（上限 100）** —— 每条候选自带 `-3 ~ +3`，你选哪条就按哪条结算；自己手打的回复不加减
- 🖼 **共享素材库** —— 角色（多张立绘 × 情绪标签）和背景分开管理，同一个角色可以给多个好友用
- 🧑 **人设 + 关系** —— 「我的人设」全局通用，「和好友的关系」每个好友单独写，写清楚之后 AI 腔会明显减少
- 📜 **过往记录浮窗** —— 随时翻看完整聊天记录
- 🧩 **容错解析** —— 模型输出格式出错时会自动修复/换格式重试，不会把一堆 JSON 炸在页面上

## ⚠️ 先读这一段：隐私与风险

**这不是一个"装完就无脑用"的插件，请先确认你能接受下面几点。**

1. **你好友的私聊内容会被发送给第三方大模型。**
   每次生成候选，插件会把最近一段聊天记录（默认最多 100 条，含好友的原话）、
   你填的人设与关系描述，一起发给**你自己配置的 LLM 服务商**。
   **你的好友对此并不知情。**
   → 请只在你认为合适的场景使用；必要时把 `history_limit` 调小；人设里不要写真实姓名、住址、公司等敏感信息。

2. **数据都留在本机。** 聊天记录存在 `data/plugin_data/astrbot_plugin_galgame_friend/` 的 SQLite 里，未加密，插件不向任何其他地方上传数据。

3. **NapCat 挂个人 QQ 号有被风控的可能。** 这是 NapCat 与 QQ 之间的风险，与本插件无关，但请自行评估。

4. **好消息：AI 说的话不会自己发出去。** AI 的输出永远只是页面上的**候选按钮**，必须你点了才会发送。
   所以即使好友在消息里写「忽略之前的指令……」，最坏结果也只是候选台词变得奇怪，不会自动发给别人。

| **NapCat** | 用于登录你的 QQ 号并提供 OneBot v11 接口（或任何兼容 OneBot v11 的协议端） |
| **一个支持 OpenAI 兼容接口的大模型** | 例如 DeepSeek、通义、智谱、硅基流动等 |

## 安装

**方式一：插件市场（推荐）**
AstrBot WebUI → 插件 → 插件市场 → 搜索「好友 Galgame」→ 安装。

**方式二：从仓库地址安装**
AstrBot WebUI → 插件 → 安装插件 → 填入仓库地址
`https://github.com/rarararar-max/astrbot_plugin_galgame_friend`

**方式三：手动**
把整个 `astrbot_plugin_galgame_friend` 目录放进 `<AstrBot>/data/plugins/`，然后在 WebUI 里重载插件。

> 插件仓库：<https://github.com/rarararar-max/astrbot_plugin_galgame_friend>

## 三步上手

> **开箱即用**：插件自带一套示例立绘（6 种情绪）和一张示例背景。全新安装后第一次启动会**自动导入**，
> 你绑好好友就能直接看到画面，不必先自己找图。示例素材随时可以删掉，删错了点「角色库」里的
> 「**载入插件自带的示例素材**」就能恢复。

1. **建角色** → 侧边栏「插件页面 → 好友 Galgame」→「**角色库**」→ 输入名字新建 →
   **上传立绘** → 给每张立绘**打情绪标签**（如 高兴 / 害羞 / 生气，可以自己输入）
   > 标签很重要：AI 只能从你实际拥有的标签里选表情。同一个角色传多张不同表情的立绘，效果最好。
   > 想用自带的示例角色就直接跳过这步。
2. **传背景** →「**背景库**」→ 上传一张背景图（不传也能用，只是没有背景）
3. **绑定好友** → 让好友给机器人**发一条私聊**（必须有真实消息，插件才知道有这个会话）→
   回「**好友**」页 → 在「最近私聊」里点「绑定」→ 选好角色和背景 → 在「人设」页填上你自己是谁

之后好友每发一条消息，页面就会自动出现台词、候选和立绘变化。

## 配置项

在 WebUI 的插件详情页里配置：

| 配置 | 默认 | 说明 |
|---|---|---|
| 回复候选条数 | `3` | 每次生成几条候选（1~6） |
| 生成候选时注入的最近消息条数 | `100` | 越多越懂上下文，也越费 token（约等于 50 轮对话） |
| 好友连发消息时的等待秒数 | `2.5` | 好友连发多条时等他停手再请求一次，省钱也不刷过期候选；设 0 关闭 |
| 让 AI 直接看好友发的图片/表情包 | 开 | 模型支持图片就直接看；不支持则自动改用 AstrBot 的「默认图片转述模型」；都没配就显示 `[图片]` 占位 |
| 保留 AstrBot 的自动回复 | 关 | 关（默认）时被接管的好友不会被 AstrBot 自动回复；开则完全不动 AstrBot 的自动回复 |
| 连没绑定的好友也不自动回复 | **关** | 默认只有你绑定过的好友会被接管，其他私聊照旧。想让**所有私聊**都手动回再打开 |
| 军师人设提示词 | 空 | 给 AI 的额外风格指令，一般留空即可（见下方「我的人设」） |

### 「我的人设」和「军师人设提示词」有什么区别？

- **我的人设 / 和好友的关系**：在**插件页面里**填（「人设」页 + 「好友」页）。这是**最重要的一项** ——
  写清楚你是谁、说话什么风格、和这位好友什么关系，AI 的台词就会从"客服体"变成真人语感。
- **军师人设提示词**（配置项）：给 AI 的额外系统指令，一般**留空**。

## 可选优化

### 让回复更快更省钱：关掉思考模式

很多新模型默认开启"思考模式"，实测**约 85% 的输出 token 花在思考上**，而生成三条候选并不需要深思。

在 AstrBot「模型提供商」→ 你的模型 →「**自定义请求体参数**」里填：

```json
{"thinking": {"type": "disabled"}}
```

（不同服务商的参数名可能不同，可查阅对应文档。）

### 语音消息转文字

AstrBot「配置文件 → 默认语音转文本模型」配置后，好友的语音会先转成文字再交给 AI，回复能真的接上内容。

### 图片转述

如果你的对话模型不能看图，在 AstrBot「配置文件 → 默认图片转述模型」里指定一个能看图的模型，
插件会在需要时把图片转成文字描述。

## 常见问题

**Q：AI 写的话一股客服味儿？**
在「人设」页认真填「我的人设」（年龄、职业、说话习惯、口头禅、打不打标点），
并在「好友」页给这位好友写「关系描述」。写得越具体，效果越明显。

**Q：立绘一直不变？**
角色需要有**多个情绪标签的立绘**。只有一张图、一个标签时，AI 没有别的选择。
去「角色库」给立绘多打几个标签、或上传几张不同表情的图。

**Q：好友发消息后机器人不回我了？**
这是设计如此：被接管的好友由你手动回。想恢复自动回复，打开配置里的「保留 AstrBot 的自动回复」。

**Q：我其他好友的私聊也不自动回复了？**
检查配置里的「连没绑定的好友也不自动回复」，默认是**关闭**的。

**Q：页面白屏？**
按 F12 看浏览器控制台报错，附上报错提 Issue。同时确认插件已启用、AstrBot 版本 ≥ 4.27。

**Q：候选里出现一大段 JSON？**
插件有多层容错（修复 → 换格式重试），如果仍然出现请把模型名和当时的输出贴出来。

**Q：示例立绘和背景是哪里来的？可以商用吗？**
是随插件一起分发的示例素材（AI 生成，已压缩成 WebP，共约 1.4 MB），只为让你装完就能看到画面。
代码以本仓库的许可为准；示例素材请当作**演示用途**，要正式使用请换成你自己拥有版权的图。

## 已知限制

- 只处理**私聊**，不处理群聊
- 好感度目前只做记录与展示，不影响剧情分支
- 立绘只按情绪标签切换，没有做到表情差分级别的精细
- 素材库的图片不会自动清理未引用的文件（删除库里的条目不会删除磁盘上的图，
  这也是示例素材能被恢复的原因）
